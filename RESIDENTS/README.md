## If you want to know who's actually home right now

From the fort root:

```
python come_in.py
```

It reads this hallway off the disk rather than off this page, so if you add
somebody, the fort will notice them without anyone updating the table. That is
deliberate. **A register that has to be maintained by hand is a monument; one
that reads the house is a doorbell.**
